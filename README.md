# React Essentials

This repository is a beginner-friendly React project created to practice and understand core React concepts from a course. It demonstrates how React components work together to build a small interactive UI.

## What this project covers

The app introduces several fundamental React ideas:

- Components: breaking the UI into reusable pieces
- JSX: writing markup-like syntax inside JavaScript
- Props: passing data from parent to child components
- State: managing data that changes over time with `useState`
- Event handling: responding to clicks and updates
- Conditional rendering: showing different content based on state
- Lists and keys: rendering repeated content from arrays
- Component composition: combining small building blocks into a full interface

## Project overview

The app includes:

- A header section introducing the React learning journey
- A "Core Concepts" section with cards for important React ideas
- An "Examples" section with tabs for different topics
- Interactive tab switching to display related examples

## Main files

- `src/App.jsx` – main application component and tab logic
- `src/data.jsx` – example content and concept descriptions
- `src/components/` – reusable UI components such as headers, concept cards, and tab buttons
- `src/index.jsx` – React entry point
- `src/index.css` – styling for the app

## Tech stack

- React
- Vite
- JavaScript / JSX
- CSS

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Learning purpose

This project is useful for anyone who wants to understand the basics of React in a practical way by building a simple app rather than only reading theory.
